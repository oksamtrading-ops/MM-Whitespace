# Object 2 — the drill core

**What it is.** A length of split diamond-drill core, cut lengthwise, lying
in a core tray. The most recognisable object in the practice's world: it is
what "evidence" looks like at a mine.

**Material.** Stone. A cool grey rock (cool grey 7 `#97999B` in the light,
cool grey 11 `#53565A` in the shade), fine-grained, matte, with a faint
sawn-flat face. One thin mineralised band across it in the brand green
`#86BC25`, no wider than a twelfth of the core's diameter. The tray is
black.

**Palette.** Greys 7 to 11, black, one green band. No warm rock colours, no
rust, no quartz white.

**Lighting.** The same one key light as object 1, upper-left. The sawn face
catches it; the curved back falls to black.

**Camera.** Three-quarter from above, 35mm equivalent, the core running from
lower-left to upper-right and leaving the frame on both sides so it reads as
a length, not a piece.

**Allowed angles.** Static. No rotation.

**Where.** The review board's empty state ("Nothing to review") and the
evidence panel's empty state ("No excerpt was recorded"). Never on the
dashboard.

**Files.** WebP/AVIF at 640×360 and 1280×720, at most 300 KB; fallback a
flat SVG of the core as a rounded grey bar with a green band.
